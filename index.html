      🔄 Multiple profiles

      Use the dropdown in the header to switch between contexts such as Baby, Automotive, Pool Cleaning, or any custom profile you create.

      Each profile keeps its own quick-log buttons and event history.

      ⚙️ Customize quick buttons

      Go to the Setup tab to:

      • Add new buttons (name + emoji icon)
      • Delete buttons you don’t need
      • Create entirely new profiles

      📝 Logging

      Tap a quick button → optionally adjust time and add notes → Save. Everything is timestamped and stored locally.

      ⏰ Reminders

      Create future reminders with fixed or custom intervals. Calendar months are true calendar months; 6 weeks = 42 days.

      Browser notifications only work while this page stays open (or in a background tab).

      📏 Growth (Baby profile)

      The Growth tab appears only when the Baby profile is selected. Track weight, length and head circumference.

      💾 Backup

      Export a JSON file regularly. You can re-import it on the same or another device that opens this HTML file.
